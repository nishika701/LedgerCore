# LedgerCore

LedgerCore is a distributed double-entry ledger system built using Spring Boot.

The goal of this project is to simulate how real financial systems process money transfers while ensuring consistency, reliability, and auditability.

---

## Features Implemented

- Account entity
- Transfer entity
- LedgerEntry entity
- UUID-based primary keys
- Optimistic locking
- JPA relationships
- Bean Validation
- Double-entry accounting model
